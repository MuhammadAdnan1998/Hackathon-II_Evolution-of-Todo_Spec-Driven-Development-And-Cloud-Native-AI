# Data Model: Full-Stack Todo Web Application

## Entity: Todo

### Fields
- **id** (Integer, Primary Key, Auto-increment)
  - Unique identifier for each todo
  - Automatically generated by the database

- **title** (String, Required, Max length: 255)
  - The main text content of the todo
  - Must be 1-255 characters

- **completed** (Boolean)
  - Indicates whether the todo is completed
  - Default value: false

- **priority** (Enum: 'low', 'medium', 'high')
  - Priority level of the todo
  - Default value: 'medium'

- **tags** (String, Optional, JSON format)
  - Comma-separated tags or JSON array for categorizing todos
  - Can be null if no tags are assigned

- **due_date** (DateTime, Optional)
  - Deadline for the todo completion
  - Can be null if no deadline is set

- **created_at** (DateTime)
  - Timestamp when the todo was created
  - Automatically set when record is created

- **updated_at** (DateTime)
  - Timestamp when the todo was last modified
  - Automatically updated when record is modified

### Validation Rules
- Title must be 1-255 characters
- Completed must be boolean (true/false)
- Priority must be one of: 'low', 'medium', 'high'
- Due date must be a valid date/time if provided
- Created_at and updated_at are automatically managed

### Relationships
- No direct relationships with other entities in this initial implementation
- Future expansion could include User relationship for multi-user support
