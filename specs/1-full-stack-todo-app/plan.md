## Technical Context

### Architecture Overview
- **Frontend**: Next.js application (React-based framework)
- **Backend**: FastAPI application (Python-based web framework)
- **Database**: SQLModel with Neon PostgreSQL database
- **Data Flow**: UI → API → DB
- **Development Environment**: Local development with environment variables

### Technology Stack
- **Frontend Framework**: Next.js 14+ with TypeScript
- **Backend Framework**: FastAPI 0.100+ with Python 3.11+
- **Database ORM**: SQLModel (combines SQLAlchemy and Pydantic)
- **Database Provider**: Neon (serverless PostgreSQL)
- **API Communication**: REST API with JSON payload
- **Environment Management**: Environment variables via .env files

- Implementation must occur on `phase-2` branch
- All code must be generated by Claude from specifications (no manual coding)
- Must maintain modular decoupling between frontend, backend, and database layers
- Must follow Twelve-Factor App methodology for production readiness
